# Amazon Store Sales and Profit Analysis

## 📊 Project Overview

This project presents a 2-page Power BI dashboard designed to analyze Amazon store sales, profit performance, customer behavior, orders, and shipping insights.

The dashboard provides an interactive view of business performance and helps identify important trends and insights for better decision-making.

## 🎯 Project Objectives

- Analyze overall sales and profit performance
- Track total sales, orders, and average order value
- Identify monthly sales trends
- Analyze sales across product categories
- Understand customer and order patterns
- Analyze payment modes and customer types
- Explore shipping and operational insights
- Present key business insights through interactive Power BI dashboards

## 🛠️ Tools Used

- Power BI
- Microsoft Excel
- DAX

## 📑 Dashboard Pages

### Page 1 — Executive Sales Performance

This dashboard provides an overview of Amazon store sales and profit performance using key performance indicators and interactive visualizations.

Key areas include:

- Total Sales
- Total Orders
- Average Order Value
- Sales Trends
- Category-wise Sales
- Sales and Profit Analysis

### Page 2 — Customer, Order & Shipping Insights

This dashboard focuses on customer behavior, order patterns, payment modes, and shipping-related insights.

Key areas include:

- Customer Analysis
- Customer Types
- Order Analysis
- Payment Modes
- Shipping Insights
- Geographic Analysis

## 📈 Key Insights

The dashboard helps identify:

- Overall sales and order performance
- Monthly sales trends
- High-performing categories
- Customer and order patterns
- Payment preferences
- Shipping-related performance
- Business areas that can support better decision-making
